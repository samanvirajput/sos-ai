# Roadmap

## Near-term
- [ ] Voice input -- Web Speech API integration for hands-free use
- [ ] Mobile app -- React Native port of the frontend
- [ ] Memory visualization -- timeline view of stored memories
- [ ] Export conversation -- download full history as PDF journal

## Medium-term
- [ ] Self-improving responses -- integrate correction loop from
      self-correcting-adaptive-llm for personalization over time
- [ ] Crisis escalation -- optional integration with crisis hotline
      directory (Befrienders, iCall) surfaced contextually
- [ ] Therapist handoff mode -- structured summary export for
      professional follow-up

## Long-term
- [ ] Fully local mode -- replace Gemini with local model entirely,
      zero external calls
- [ ] Federated memory -- sync memories across devices (local network,
      no cloud)
- [ ] Multilingual support -- emotion detection + responses in Hindi,
      Tamil, and other Indian languages
